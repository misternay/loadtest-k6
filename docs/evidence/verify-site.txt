
การตรวจสอบเว็บไซต์ — loadtest-k6/site
====================================================================================

[ผ่าน] 1. ไฟล์ที่ต้องมีและโครงสร้างหน้าเว็บ
   ok   ไฟล์ที่กำหนดไว้มีครบทั้ง 33 ไฟล์
   ok   ไฟล์สคริปต์และไฟล์ข้อมูลมีเนื้อหาจริง ไม่มีไฟล์ว่าง
   ok   พบไฟล์ HTML ทั้งหมด 15 หน้า ตรงตามที่กำหนด
   ok   ทุกหน้าอ้าง assets/css/main.css และ assets/js/site.js ครบ

[ผ่าน] 2. ลิงก์ภายในทุกตัวต้องชี้ไปไฟล์ที่มีอยู่จริง
   ok   ลิงก์ภายในทั้งหมด 89 ลิงก์ชี้ไปไฟล์ที่มีอยู่จริง
   ok   มีลิงก์ไปเอกสารทางการ 2 แห่ง ซึ่งได้รับอนุญาตให้เป็นลิงก์ภายนอกได้
   ok   ลิงก์ภายนอกทุกแห่งชี้ไปที่เอกสารทางการของ k6

[ผ่าน] 3. ต้องไม่มี asset ภายนอกที่ถูกโหลดเข้ามา
   ok   ไม่มีการโหลด CSS, JS, รูป หรือ iframe จากภายนอกเลย
   ok   ไม่มี url() ที่อ้างไฟล์ภายนอกใน CSS
   ok   ไม่มี @import ใน CSS
   ok   ไม่มี @font-face ใช้ฟอนต์ของระบบตามที่กำหนด

[ผ่าน] 4. ไม่มีข้อความต้องห้ามในหน้าที่ผู้ใช้เห็น
   ok   ไม่พบข้อความต้องห้ามทั้ง 8 รูปแบบ

[ผ่าน] 5. ภาษาของหน้า ชื่อเรื่อง และคำอธิบาย
   ok   ทุกหน้า (15 หน้า) มี lang="th", title, meta description, viewport และ charset ครบ
   ok   ทุกหน้า (15 หน้า) ประกาศ favicon เป็น SVG ด้วยพาธสัมพัทธ์ที่ถูกต้อง
   ok   ไฟล์ favicon.svg เป็นไอคอนเส้น SVG ขนาด 32×32 ใช้สี #1f4e79 ไม่มี gradient และไม่ดึงของภายนอก

[ผ่าน] 6. ต้องไม่มีอักขระ emoji ในหน้าเว็บ
   ok   ไม่พบอักขระ emoji ในหน้าเว็บและไฟล์สไตล์/สคริปต์
   ok   ใช้ inline SVG เป็นไอคอน (ในหน้าเว็บ 136 จุด และในชุดไอคอนของ site.js อีก 50 รูป)
   ok   ไม่ใช้เครื่องหมายถูก กากบาท หรือดาว เป็นไอคอน

[ผ่าน] 7. ไวยากรณ์ของ JavaScript ทุกไฟล์และทุกสคริปต์ในหน้า
   ok   ไฟล์ JavaScript ทั้ง 5 ไฟล์ผ่านการตรวจไวยากรณ์
   ok   สคริปต์ที่ฝังในหน้าเว็บ 24 ชุดผ่านการตรวจไวยากรณ์ทั้งหมด
   ok   ทุกหน้าที่เรียกใช้โมดูล ได้โหลดไฟล์ของโมดูลนั้นครบ (ตรวจ calc, charts, quiz, storage)
   ok   สคริปต์ k6 ทั้ง 5 ไฟล์มี export default, export const options และกลไกตรวจปลายทางครบ

[ผ่าน] 8. ความสอดคล้องของไฟล์ข้อมูลกับหน้าที่อ่านมัน
   ok   อภิธานศัพท์มีทั้งหมด 69 คำ (metric 19 + ศัพท์ 50) เกินเกณฑ์ 40 คำ
   ok   รหัสของ metric และศัพท์ไม่ซ้ำกัน
   ok   ไฟล์ข้อมูล latency สอดคล้องกัน: sample 1155 ค่า, ผลรวม bins 1155 ค่า, ค่า n ที่ประกาศ 1155
   ok   ข้อมูลในไฟล์ latency เรียงจากน้อยไปมากแล้ว ทำให้ตรวจสอบด้วยมือได้
   ok   ตัวเลขสำคัญในบทที่ 1 ตรงกับไฟล์ข้อมูล (4 ค่า)
   ok   ตัวเลข p50, p75, p90, p95, p99, max และค่าเฉลี่ยในบทที่ 4 ตรงกับไฟล์ข้อมูล
   ok   ตารางข้อมูลทุกตัวถูกครอบด้วย .table-wrap (จึงเลื่อนแนวนอนได้บนจอมือถือ)
   ok   หน้า examples อ้างถึงสคริปต์ทั้งห้าไฟล์
   ok   คลังแบบทดสอบมี 6 ชุด ตรงกับจำนวนบทเรียน
   ok   แบบทดสอบมีทั้งหมด 36 ข้อ (ชุดละ 6 ข้อ)
   ok   สำเนาสคริปต์ใน site/examples/ ตรงกับต้นฉบับใน k6/ ทั้งห้าไฟล์

[ผ่าน] 9. ธีมสว่าง/มืด: สคริปต์ตั้งธีมก่อนวาด ปุ่มสลับ และโทเคนครบทั้งสองธีม
   ok   ทุกหน้า (15 หน้า) มีสคริปต์ตั้งธีมใน <head> ก่อนลิงก์ CSS และเป็นสคริปต์ซิงโครนัส
   ok   ปุ่มสลับธีมเป็น <button> จริง มี aria-label ภาษาไทย มี hover/active และเป้ากด ≥ 24×24 px
   ok   ปุ่มทั้งเว็บมีสถานะ focus-visible (คุมปุ่มสลับธีมด้วย)
   ok   โทเคนครบทั้ง 23 ตัวในทั้ง :root และ [data-theme="dark"]
   ok   มี media query prefers-color-scheme: dark เป็นค่าตั้งต้นตามระบบ พร้อมโทเคนครบ 23 ตัว
   ok   โหมดมืดออกแบบใหม่สำหรับพื้นเข้ม: ไม่ใช้ดำ/ขาวสนิท ขอบเป็นเส้นโปร่งแสง และ --accent สว่างขึ้นจนผ่าน 4.5:1 (accent/bg = 9.19:1, fg/bg = 14.89:1)
   ok   charts.js ไม่มีสีฮาร์ดโค้ดเลย — สีกราฟ (25 จุด) อ่านจาก CSS variable ทั้งหมด
   ok   ไฟล์ JavaScript อื่น ๆ ก็ไม่มีสีฮาร์ดโค้ดเช่นกัน
   หมายเหตุ: โทเคนโหมดสว่างประกาศที่ :root · โหมดมืดประกาศซ้ำสองที่ (เมื่อผู้ใช้เลือก และเมื่อระบบเป็นค่าตั้งต้น)

[ผ่าน] 10. บล็อก "ใจความสำคัญ" และจุดที่ต้องจำในหน้าเนื้อหา
   ok   หน้าเนื้อหาทั้ง 7 หน้ามีบล็อกใจความสำคัญ 3–5 ข้อบนสุดของเนื้อหา พร้อมคลาส keypoint และ key-figure (01-tps.html 4 ข้อ · 02-vu.html 4 ข้อ · 03-metrics.html 4 ข้อ · 04-percentiles.html 4 ข้อ · 05-load-profiles.html 4 ข้อ · 06-read-results.html 4 ข้อ · troubleshooting.html 3 ข้อ)
   ok   คลาสของส่วนเน้นมีนิยามครบ ใช้ tabular-nums กับตัวเลขที่ต้องจำ และไม่ใช้การ์ดมุมโค้ง/ขอบซ้ายสี
   ok   แถบความคืบหน้าการอ่านใช้สีจาก CSS variable จึงเปลี่ยนตามธีมได้

[ผ่าน] 11. สาระครบตามเกณฑ์ส่งมอบหลังตัดสำนวน
   ok   สาระตามเกณฑ์ส่งมอบอยู่ในหน้าเนื้อหาครบ (19 หัวข้อ)
   ok   บทเรียนมี 6 หน้าเท่าเดิม
   ok   อภิธานศัพท์ครบ 69 คำ (metric 19 + ศัพท์ 50)
   ok   หน้าอภิธานศัพท์สร้างจาก assets/data/metrics.json จึงครบทุกคำโดยอัตโนมัติ
   ok   หน้าปัญหาที่พบบ่อยมี 20 ข้อ แบ่งเป็น 5 กลุ่มตามอาการ แต่ละข้อมีครบทั้งอาการ/สัญญาณ สาเหตุที่เป็นไปได้ และวิธีแก้
   ok   แบบทดสอบยังมี 36 ข้อใน 6 ชุด พร้อมเฉลยและคำอธิบายครบทุกข้อ

[ผ่าน] 12. โมดูลที่เพิ่มในรอบนี้: สี่คำ · สไลเดอร์ · กายวิภาค · หน้างานจริง
   ok   หน้าแรกมีส่วน "สี่คำที่ต้องจำ" ก่อนเส้นทางการอ่าน ครบ 4 คำ แต่ละคำมี ความหมาย · ตัวเลขจากการรัน · กับดัก พร้อมประโยคปิดท้ายเดียว
   ok   บทเรียนทั้ง 6 บทมีบรรทัดอ้างกลับไปยังส่วนสี่คำ ไม่เกิน 12 คำต่อหน้า (01-tps 11 คำ · 02-vu 11 คำ · 03-metrics 11 คำ · 04-percentiles 11 คำ · 05-load-profiles 11 คำ · 06-read-results 11 คำ)
   ok   ช่องกรอกตัวเลขทั้ง 11 ช่องมีสไลเดอร์คู่กัน ซิงก์สองทาง มี <label for> แยก และ aria-valuetext อ่านออกเสียงเป็นค่าจริงพร้อมหน่วย (11 ตัว)
   ok   หน้ากายวิภาคแสดง examples/load.js จริงพร้อมหมายเลขกำกับ 9 ตัว (มากกว่าเกณฑ์ขั้นต่ำ 7) ทุกตัวมีคำอธิบายใต้โค้ดครบ และ anchor ตรงกับบรรทัดจริงในไฟล์
   ok   workflow.html มีเวิร์กโฟลว์ 6 ขั้น เช็คลิสต์ 8 ข้อที่เป็น checkbox จริงพร้อม label ครบ ใช้คีย์ ltk6.checklist.v1 และไม่ถูกนับเป็นบทเรียนที่ 7
   ok   เมนูด้านข้างมีกลุ่ม "ใช้งานจริง" ต่อจากกลุ่มบทเรียน และทุกหน้า (15 หน้า) อยู่ในเมนูชุดเดียวกัน จึงมีลิงก์ไป workflow.html ครบทุกหน้า
   หมายเหตุ: ด่านชุดนี้ตรวจเชิงโครงสร้างฝั่งไฟล์ ส่วนการลากสไลเดอร์ การติ๊กเช็คลิสต์ และคอนทราสต์ของ track/thumb วัดจากเบราว์เซอร์จริงใน scripts/browser-check.mjs
