จำนวนคำ before/after ต่อหน้า — หลักฐานการตัดสำนวน
================================================================================================

วิธีวัด
  1) ก่อนเริ่มแก้ ได้คัดลอก site/ ทั้งโฟลเดอร์ไปเก็บไว้นอกโปรเจกต์ที่
     /tmp/ltk6-baseline-1hog4h/site
     (โปรเจกต์นี้ไม่มี git จึงต้องเก็บสำเนาไว้เอง) สำเนานั้นถูกลบหลังวัดเสร็จ
     และไม่มีไฟล์ชั่วคราวใดถูกทิ้งไว้ในโปรเจกต์
  2) นับเฉพาะข้อความที่ผู้ใช้เห็นใน <body> ตัด <script>, <style>, คอมเมนต์ HTML
     และ (สำหรับคอลัมน์ คำในเนื้อความ) ตัด <pre>, <table>, <code> ออกด้วย
     เพราะตัวเลข ตาราง และโค้ดไม่ใช่สำนวนที่ควรตัด
  3) แบ่งคำภาษาไทยด้วย Intl.Segmenter("th", word) ซึ่งเป็นตัวแบ่งคำของ ICU
     ไม่ใช่นับจากช่องว่าง เพราะภาษาไทยเขียนติดกันโดยไม่มีช่องว่าง

ตัวเลข before ในตารางนี้คือค่าที่วัดจากสำเนาเดิมก่อนการแก้ไขใด ๆ
รันซ้ำได้ด้วย: node scripts/word-count.mjs --before <สำเนาเดิม> --after site

================================================================================================

โปรเจกต์นี้ไม่มี git สำเนา site/ ก่อนแก้จึงถูกลบหลังวัดเสร็จ ค่าอ้างอิงก่อนแก้

    node scripts/word-count.mjs --check
