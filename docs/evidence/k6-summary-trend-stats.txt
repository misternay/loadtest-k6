  บทที่ 6 เดิมสรุปว่า "p99 ไม่ปรากฏบนหน้าจอโดยค่าเริ่มต้น ต้องตั้ง threshold ที่อ้างถึง

ค่าเริ่มต้นของ k6 v2.2.0 (จาก k6 run --help):
  --summary-trend-stats    define stats for trend metrics (default 'avg, min, med, max, p(90), p(95)')
  --summary-mode string    determine the summary mode, "compact", "full" or "disabled" (default "compact")
  --summary-export string  output the end-of-test summary report to JSON file
  -o, --out uri            uri for an external metrics database

จุดสังเกต
  • p(99) และ p(50) ปรากฏขึ้นมาแล้ว โดยไม่ต้องแก้สคริปต์และไม่ต้องตั้ง threshold
  • ค่า avg, min, med, max, p(90), p(95) เท่าเดิม เพราะวิธีนี้เปลี่ยนแค่ "สิ่งที่พิมพ์"
    ไม่ได้เปลี่ยนข้อมูลหรือการคำนวณ
  • ตัวเลือกนี้มีผลกับ Trend metric **ทุกตัว** ไม่ใช่เฉพาะ http_req_duration
    (ดูว่า iteration_duration ก็ได้สถิติชุดเดียวกันด้วย)
  • ตัวเลือกนี้ **ไม่เปลี่ยนผลการตัดสิน threshold** — บล็อก THRESHOLDS ยังใช้เกณฑ์
    ที่เขียนไว้ในสคริปต์เท่านั้น
  • p(99.9) ใช้ได้เช่นกัน แต่กับ 120 ข้อตรวจในตัวอย่างนี้ค่าจะเท่ากับ max
    เพราะจำนวนตัวอย่างยังไม่มากพอที่จะแยกหางได้จริง

สรุปความต่างของทั้งสามวิธี
======================================================================

  ตัวเลือก                  เปลี่ยนอะไร                    ได้ p99?
  ---------------------------------------------------------------------------
  (ไม่ใส่อะไร)              –                              ไม่ได้
  --summary-trend-stats     สิ่งที่พิมพ์บนหน้าจอสรุป         ได้ บนหน้าจอ
  --summary-export=file     เขียนสรุปผลเป็นไฟล์ JSON        ได้ ถ้าใส่ --summary-trend-stats ควบ
  -o csv=file               ส่งข้อมูลรายคำขอออกเป็นไฟล์     ได้ แต่ต้องคำนวณเอง
  -o json=file              เหมือน csv แต่มี tag ครบ         ได้ แต่ต้องคำนวณเอง
  threshold ที่อ้าง p(99)   ผลการตัดสิน + แสดงใน THRESHOLDS  ได้ แต่ผูกกับการตัดสินผ่าน/ไม่ผ่าน

  เลือกใช้
  • อยากเห็นเร็ว ๆ ระหว่างพัฒนา → --summary-trend-stats
  • ต้องเทียบหลายรอบด้วยสคริปต์  → --summary-export
  • ต้องวิเคราะห์เชิงลึกเอง       → -o csv / -o json
  • ต้องให้ไปป์ไลน์ตัดสินด้วย p99 → ตั้ง threshold ที่อ้าง p(99) (ไม่ใช่แค่ดู)
